Quiz App

A simple, interactive quiz application built with HTML, CSS, and JavaScript.
Users can answer multiple‑choice questions, and receive instant feedback.

Features

Multiple‑choice questions
Instant answer validation
Score tracking
Clean, responsive UI
Lightweight and fast

How It Works

The quiz uses JavaScript to:
Store questions, options, and correct answers
Render each question dynamically
Validate user selections

Tech Stack

HTML — structure
CSS — styling
JavaScript — quiz logic, scoring, and dynamic rendering

Project Goals

This project was created to practice:
DOM manipulation
Event handling
Conditional logic
Dynamic UI updates
Clean, modular JavaScript structure
